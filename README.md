This program was developed as a hospital patient management system designed to organize and manage patients within a hospital waiting room. When users access the program, they are presented with the option to either visit an existing patient or check in a new patient.

When checking in a new patient, the system collects and stores the necessary patient information. When visiting a patient, the user can search for and view a patient's information by entering their name. For demonstration purposes, the system also provides an option to display information for all patients by entering "all."

The application was designed using object-oriented programming principles, specifically inheritance and encapsulation.
